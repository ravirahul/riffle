Riffle

Privacy policy

Last updated 30 October 2026

Riffle runs entirely on your computer. It doesn't collect, store or send any personal data, file names, file contents or usage statistics to anyone, including us.

What Riffle keeps on your PC

  • An index of file and folder names, sizes and dates, so search is instant.
  • File fingerprints (hashes) from duplicate scans, so later scans are faster.
  • If you turn on visual search: small previews and image fingerprints of the folders you choose.
  • Your settings, such as theme and filters.

All of this lives in %LOCALAPPDATA%\Riffle on your PC. Uninstalling removes the index and fingerprints.

When Riffle uses the internet

  • Once a day it asks GitHub whether a newer version exists. The request contains no information about you or your files.
  • If you choose to add visual search, it downloads that component from GitHub.
  • If you add a shared Google Drive folder to visual search, it reads that folder's previews from Google using the API key you provide.

Your files

Riffle only changes files when you ask it to, for example sending duplicates to the Recycle Bin or clearing caches you confirmed. It never uploads files.
