    Connect Google Drive

    Shared folders need a free Google API key. About 3 minutes, once:

    1. Create a Cloud project (no billing).
    2. Enable the Drive API.
    3. Credentials → Create credentials → API key. Copy it.

    The folder must be shared as Anyone with the link. Riffle reads previews only; it never changes your files.

    Find duplicates

    Files with identical contents, even when they have different names. One copy of each is always kept, and removed copies go to the Recycle Bin.

    App, system and code-library folders are skipped so nothing an app needs is offered for removal.

    Clean up

    Space you can get back, with the reason for each. Your own files go to the Recycle Bin. Caches and temp files are deleted, because apps rebuild them.

    Where your space goes
    Click a block to look inside. Sizes come from the index, so system and library folders Riffle skips aren't counted.

    Welcome to Riffle

    • Press Ctrl + Shift + Space anywhere to search every file on this PC.
    • Select a file and press Space to preview it.
    • Duplicates and Clean up show what's taking space, and only act when you say so.
    • Everything stays on this PC. Riffle never uploads your files.
